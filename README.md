# Gamenhalam

Game quản lý guild thợ săn viết bằng Flutter.

- Tuyển hunter theo char (mage, hunter, warrior, tank, healer), mỗi char có nội tại riêng.
- Giao nhiệm vụ săn / thu thập theo buổi sáng – trưa – đêm, chiến đấu theo lượt kiểu Action Value.
- Trang bị, rèn đồ, thăng hạng hunter và thị trấn.
- Sự kiện hằng tuần, sàn chứng khoán với 6 công ty và cổ tức.

## Chạy game

```sh
flutter pub get
flutter run
```

## Kiểm thử

```sh
flutter test
flutter analyze
```
